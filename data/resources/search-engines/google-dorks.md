## Google 高级搜索

利用搜索操作符（Dorks）精准检索公开索引内容。

## 资源地址

- 官方入口：[https://www.google.com/advanced_search](https://www.google.com/advanced_search)

## 使用场景

适用于线索初筛与公开索引内容检索阶段，可配合搜索操作符（Dorks）进一步缩小结果范围，定位散落在公开网络中的目标信息。

## 常用语法

```bash
# 限定站点内搜索
site:example.com "password"

# 搜索指定文件类型
filetype:pdf "internal use only"

# 排除关键词
"admin panel" -github.com
```

## 使用建议

- 仅面向公开、可合法访问的信息渠道，遵守目标站点的服务条款与 robots 协议；
- 关键结论建议结合其他同类工具交叉验证，避免单一来源误判；
- 涉及个人信息时请注意合规边界，不得用于任何未经授权的用途。
